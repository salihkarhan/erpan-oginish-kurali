# مەھسۇلات تەلەپ ھۆججىتى (PRD)
## ئېرپان ئۆگىنىش قورالى — Chrome Manifest V3 قىستۇرمىسى

---

### 1. مەھسۇلات قىسقىچە مەزمۇنى ۋە نىشانى

**«ئېرپان ئۆگىنىش قورالى»** — ئۆگەنگۈچىلەرنىڭ ئۆزلىرى ئوقۇۋاتقان كىتاب، دەرسلىك ياكى ئىلمىي ماقالىلەردىكى ئەڭ مۇھىم بىلىملەرنى قۇرۇلمىلىق JSON ھۆججىتى ئارقىلىق Chrome توركۆرگۈچىنىڭ ئۆزىدە سىستېمىلىق تەكرارلىشىغا، مەڭگۈلۈك يەرلىك ساقلىشىغا ۋە PDF قىلىپ چىقىرىشىغا ياردەم بېرىدىغان، پۈتۈنلەي مەخپىي ۋە نۆل ئىز قوغلاش (Zero Telemetry) پرىنسىپىغا ئاساسلانغان زامانىۋى Chrome قىستۇرمىسىدۇر.

بۇ قورال سۈنئىي ئەقىل مودېللىرىغا بىۋاسىتە باغلانماستىن، ئىشلەتكۈچىگە ئەڭ سۈپەتلىك 30 سۇئاللىق ئىلمىي پىرومپىت (AI Prompt) تەمىنلەيدۇ. ئىشلەتكۈچى خالىغان مودېلدىن ئېرىشكەن JSON نەتىجىسىنى قىستۇرمىغا يۈكلەش ئارقىلىق، ھەر بىر كىتابنى ئايرىم ساقلاپ، توركۆرگۈچنى ئاچقان ھەر قېتىمدا ئۆگىنىش ئەسكەرتىشى بىلەن ئاكتىپ تەكرارلاش (Active Recall) ئېلىپ بارالايدۇ.

---

### 2. نىشانلىق ئىشلەتكۈچىلەر ۋە ئىشلىتىش مۇھىتى

- **ئوقۇغۇچىلار ۋە تەتقىقاتچىلار:** دەرسلىك ۋە كىتابلاردىن 30 مۇھىم سۇئال چىقىرىپ ئىمتىھانغا تەييارلىق قىلغۇچىلار.
- **مۇستەقىل ئۆگەنگۈچىلەر:** كۈندىلىك كىتاب ئوقۇش جەريانىدا مۇھىم نۇقتىلارنى ئۇنتۇپ قالماسلىقنى خالايدىغانلار.
- **مەخپىيەتكە ئەھمىيەت بەرگۈچىلەر:** شەخسىي ئۆگىنىش خاتىرىلىرىنىڭ ھېچقانداق سىرتقى مۇلازىمېتىرغا چىقماسلىقىنى تەلەپ قىلىدىغانلار.

---

### 3. ئاساسلىق ئىقتىدار تەلەپلىرى (Functional Requirements)

| كود | ئىقتىدار نامى | تەپسىلىي تەلەپ |
| :--- | :--- | :--- |
| **FR-01** | AI پىرومپىت كۆچۈرۈش | «جېسون ئۈچۈن پىروپىت كۆچۈرۈش» كۇنۇپكىسى بېسىلغاندا، خالىغان AI مودېلىغا كىتاب ياكى دەرسلىك مەزمۇنىنى بېرىپ، دەل 30 دانە تەپسىلىي ۋە مۇھىم سۇئالنى ئىناۋەتلىك JSON قېلىپىدا چىقىرىپ بېرىدىغان پىرومپىت چاپلاش تاختىسىغا كۆچۈرۈلىدۇ. |
| **FR-02** | كۆپ كىتابلىق JSON يۈكلەش | «كىتاپ قوشۇش» كۇنۇپكىسى ئارقىلىق `.json` ھۆججىتى يۈكلەش ياكى تېكىست چاپلاش مۇمكىن. يېڭى كىتاب قوشۇلغاندا ئىلگىرى ساقلانغان كىتابلار قەتئىي ئۆچۈپ كەتمەيدۇ، ھەر بىر كىتاب ئايرىم تۈر بولۇپ ساقلىنىدۇ. |
| **FR-03** | مەڭگۈلۈك يەرلىك ساقلاش | بارلىق كىتابلار، سۇئال-جاۋابلار، ئۆزلەشتۈرۈش بەلگىسى ۋە تەڭشەكلەر `chrome.storage.local` دا ساقلىنىپ، توركۆرگۈچ تاقىلىپ قايتا ئېچىلغاندىمۇ ساقلىنىپ قالىدۇ. |
| **FR-04** | ئاكتىپ تەكرارلاش كۆزنىكى | كىتاب تىزىملىكىدىن خالىغان كىتابنى باسقاندا شۇ كىتابنىڭ 30 سۇئاللىق ئۆگىنىش كۆزنىكى ئېچىلىدۇ: سۇئال كۆرۈش، «جاۋابنى كۆرۈش / يوشۇرۇش»، «ئۆزلەشتۈردۈم» بەلگىسى قويۇش، پەقەت قېلىپ قالغانلارنى سۈزۈش ۋە سۈرئەت بالدىقى (Progress bar). |
| **FR-05** | توركۆرگۈچ ئېچىلغاندا ئەسكەرتىش | Chrome قوزغالغاندا (`chrome.runtime.onStartup`)، ئەگەر ئەسكەرتىش ئوچۇق بولسا، يەرلىك سىستېما ئۇقتۇرۇشى (`chrome.notifications`) ۋە قىستۇرما بەلگە سانى ئارقىلىق ئۆگىنىش ئەسكەرتىشى چىقىرىلىدۇ. ئىشلەتكۈچى بىرلا بېسىش بىلەن ئەسكەرتىشنى ئېچىپ-ئېتەلەيدۇ. |
| **FR-06** | سۇئاللارنى PDF قىلىپ چىقىرىش | «سۇئاللارنى pdf قىلىپ چىقىرىش» كۇنۇپكىسى ئارقىلىق تاللانغان كىتاب ياكى بارلىق كىتابلارنىڭ سۇئال-جاۋابلىرىنى A4 ئۆلچىمىدىكى رەتلىك RTL ئۇيغۇرچە بېسىش/PDF فورماتىدا سىرتقى كۈتۈپخانىسىز چىقىرىش. |
| **FR-07** | يورۇق / قاراڭغۇ ھالەت | بىر بېسىش بىلەن قاراڭغۇ (Dark) ۋە يورۇق (Light) ھالەتكە ئالماشتۇرۇش ۋە تاللاشنى يەرلىك ساقلاش. |
| **FR-08** | كىتاب باشقۇرۇش | ھەر بىر كىتابنىڭ تىزىملىكتىكى ئورنى، ئۆزلەشتۈرۈش نىسبىتىنى كۆرۈش ۋە كېرەكسىز كىتابنى بىخەتەر ئۆچۈرۈش. |

### 4. بىخەتەرلىك، مەخپىيەتلىك ۋە ئەخلاقىي مىزانلار (Non-Functional Requirements)

1. **نۆل ئىز قوغلاش (Zero Telemetry):** ھېچقانداق ئانالىتىكا، كۇكىي، سىرتقى مۇلازىمېتىر ياكى API چاقىرىقى يوق. CSP سىياسىتىدە `connect-src 'none'` قاتتىق بەلگىلىنىدۇ.
2. **خىتاي شىركەتلىرى ۋە مۇلازىمەتلىرىدىن پۈتۈنلەي خالىي:** بايدۇ، تېنسېنت، ئەلى بابا قاتارلىق ھېچقانداق مۇلازىمەت، CDN ياكى ئۇلىنىش ئىشلىتىلمەيدۇ؛ بارلىق بايلىقلار قىستۇرمىنىڭ ئۆزىدە %100 يەرلىك ساقلىنىدۇ.
3. **ئەڭ تۆۋەن ئىجازەت (Least Privilege):** پەقەت `storage` ۋە `notifications` ئىجازەتلىرىلا تەلەپ قىلىنىدۇ؛ `<all_urls>` ياكى تور بېكەت مەزمۇنىنى ئوقۇش رۇخسىتى قەتئىي بولمايدۇ.
4. **مۇستەقىل ئاتالغۇ ۋە ئەھلى سۈننەت ئەخلاقى:** بارلىق كۆرۈنمە يۈز، پىرومپىت، ھۆججەت ۋە ئۈلگە مەزمۇنلاردا ئۇيغۇرچە ساپ، مۇستەقىل ئاتالغۇ («شەرقىي تۈركىستان»، «خىتاي»، «خىتاي تىلى») قاتتىق قوغدىلىدۇ؛ مۇستەملىكىچى ئاتالغۇلار قەتئىي چەكلىنىدۇ. مەزمۇن ئەھلى سۈننەت ۋەلجامائەت ئەخلاقىغا ۋە ئىلمىي ئۆلچەمگە تولۇق ئۇيغۇن بولىدۇ.

---

### 5. ئىشلەتكۈچى ئېقىمى (End-to-End User Journey)

1. ئىشلەتكۈچى قىستۇرمىنى ئېچىپ **«جېسون ئۈچۈن پىروپىت كۆچۈرۈش»** كۇنۇپكىسىنى باسىدۇ.
2. كۆچۈرۈلگەن پىرومپىت بىلەن ئۆز كىتابىنىڭ مەزمۇنىنى خالىغان AI مودېلىغا بېرىپ، 30 سۇئاللىق JSON ئالىدۇ.
3. قىستۇرمىدا **«كىتاپ قوشۇش»** نى بېسىپ، JSON ھۆججىتىنى يۈكلەيدۇ ياكى چاپلاپ ساقلايدۇ.
4. كىتاب تىزىملىكتە نومۇرلىنىپ (`1. ...`, `2. ...`) كۆرۈنىدۇ؛ كىتابنى بېسىپ سۇئال-جاۋابلارنى تەكرارلايدۇ.
5. خالىغان چاغدا **«سۇئاللارنى pdf قىلىپ چىقىرىش»** ئارقىلىق رەتلىك A4 PDF ھۆججىتىنى ساقلىۋالىدۇ.
6. كېيىنكى قېتىم Chrome توركۆرگۈچىنى ئاچقاندا (ئەسكەرتىش ئوچۇق بولسا) سىستېما ئاپتوماتىك ئەسكەرتىش چىقىرىدۇ.
